# Explanation

## Palindrome checker

The program removes non-alphanumeric characters and converts the remaining text to lowercase. It reverses the normalized text with `StringBuilder` and compares the two strings. If they match, the text is a palindrome.

## Vowel counter

The program converts the input to lowercase, visits every character using a loop, and increases the count when the character is `a`, `e`, `i`, `o`, or `u`.
